# Reading notes: attention

- Attention turns a query and a set of keys into weights, then averages the values with those weights.
- Scores are dot products of query and key, divided by the square root of the key size so the softmax stays
  in a useful range when vectors are long.
- Multi-head attention runs several smaller attention layers side by side and concatenates their outputs.
- Self-attention: queries, keys and values all come from the same sequence.
