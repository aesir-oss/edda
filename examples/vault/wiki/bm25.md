# BM25

BM25 scores a document for a query by adding up, for each query term, a weight for how rare the term is times a
function of how often it appears that levels off.[^bm25-notes] The parameter `k1` sets how fast term frequency levels
off and `b` how much long documents are penalized.[^bm25-notes]
