# Attention Is All You Need

Vaswani and colleagues, 2017. Proposes the [Transformer](/transformer.md), which replaces recurrence with
[attention](/attention.md). On WMT 2014 English-German translation it beat earlier models while taking less time to
train.[^vaswani2017-s6]

[^vaswani2017-s6]: Section 6.
